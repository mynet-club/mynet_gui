# 开发工具 / Development Tools

本目录包含项目开发过程中使用的各种工具脚本。

## 📋 工具列表

### 1. check-i18n.js - 国际化键值检查工具

**用途：** 检查项目中使用的国际化键值是否在 i18n 文件中正确定义

**功能：**
- 扫描所有 `.vue` 和 `.ts` 文件中的 `$t()` 和 `t()` 调用
- 解析 `src/i18n/zh-CN.ts` 和 `src/i18n/en-US.ts` 中定义的键
- 检测缺失的中文翻译键
- 检测缺失的英文翻译键
- 检测中英文翻译不一致的键
- 显示每个问题键的使用位置

**使用方法：**

```bash
# 方式1: 直接运行脚本
node dev-tools/check-i18n.js

# 方式2: 使用 npm script
npm run check:i18n
```

**输出示例：**

```
🔍 开始检查国际化键值...

📚 中文键数量: 1987
📚 英文键数量: 1779

📁 扫描文件数: 208
🔑 使用的键数量: 1063

❌ 中文翻译缺失的键:
  - common.create
    使用位置: src/components/zone/ServiceEditDialog.vue
  - common.status
    使用位置: src/layouts/MainLayout.vue

✅ 所有国际化键值检查通过！
```

**集成到工作流：**

根据项目开发规范，在以下场景需要运行此检查：
- 会话结束前，如果修改了页面文件
- 提交代码前
- 添加新的 UI 文本时

## 📝 开发规范

### 国际化开发规范

1. **禁止硬编码文本**
   - ❌ `<div>用户名</div>`
   - ✅ `<div>{{ $t('user.username') }}</div>`

2. **新增 UI 文本流程**
   - 在 `src/i18n/zh-CN.ts` 中添加中文键值
   - 在 `src/i18n/en-US.ts` 中添加对应的英文键值
   - 在组件中使用 `$t('key.path')` 引用
   - 运行 `npm run check:i18n` 验证

3. **键值命名规范**
   - 使用点分隔的路径：`module.submodule.key`
   - 使用驼峰命名：`userProfile.editButton`
   - 保持层级清晰，避免过深嵌套（不超过4层）

4. **会话结束检查清单**
   - [ ] 如果修改了 `.vue` 或 `.ts` 文件
   - [ ] 运行 `npm run check:i18n`
   - [ ] 修复所有报告的缺失键
   - [ ] 确保中英文翻译都已完成

## 🎯 最佳实践

1. **定期检查**：建议每天开发结束前运行一次检查
2. **增量修复**：发现问题立即修复，避免积累
3. **代码审查**：PR 中包含新的 UI 文本时，检查是否正确国际化
4. **文档同步**：更新翻译时同步更新相关文档
