>
> **为什么移出**：这些章节是**设想的备选**，本项目从未实现。它们和唯一可用的部署路径
> （`deployment.sh` = 本地 `npm run build` + rsync 到主机 nginx）混在同一份文档里，
> 结果是 968 行里 444 行不能执行，把人淹了。**移出不是删除**——日后真要加 CDN

>

> - `Dockerfile` / `docker-compose.yml` —— 本仓**没有**，`docker build` 第一步就失败
> - `.github/workflows` —— 本仓**没有**，CI/CD 两段是通用示例模板，不是本仓配置
> - AWS / Vercel / Netlify —— 本项目**不用**这些平台，无对应配置
>
> 本项目已于 2026-09-24 撤掉容器路线（V3-0），理由见
> `mynet_ctl/docs/knowledge-base/long-range-plan-deep.md` §4「为什么撤 Docker」。

## 🐳 Docker 部署

### Dockerfile

```dockerfile
# 多阶段构建
# 阶段1: 构建
FROM node:18-alpine AS builder

WORKDIR /app

# 复制package文件
COPY package*.json ./

# 安装依赖
RUN npm ci --only=production

# 复制源代码
COPY . .

# 构建应用
RUN npm run build

# 阶段2: 生产
FROM nginx:alpine

# 复制构建文件
COPY --from=builder /app/dist/spa /usr/share/nginx/html

# 复制Nginx配置
COPY nginx.conf /etc/nginx/nginx.conf

# 复制环境变量替换脚本
COPY docker-entrypoint.sh /docker-entrypoint.sh
RUN chmod +x /docker-entrypoint.sh

# 暴露端口
EXPOSE 80

# 启动脚本
ENTRYPOINT ["/docker-entrypoint.sh"]
CMD ["nginx", "-g", "daemon off;"]
```

### docker-entrypoint.sh

```bash
#!/bin/sh

# 替换环境变量
envsubst '${VITE_API_URL}' < /usr/share/nginx/html/index.html.template > /usr/share/nginx/html/index.html

# 启动Nginx
exec "$@"
```

### docker-compose.yml

```yaml
version: '3.8'

services:
  mynet-quasar:
    build: .
    ports:
      - "80:80"
    environment:
      - VITE_API_URL=https://api.yourdomain.com
      - VITE_WS_URL=wss://api.yourdomain.com/ws
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf:ro
    restart: unless-stopped
    networks:
      - mynet-network

  nginx-proxy:
    image: nginx:alpine
    ports:
      - "443:443"
    volumes:
      - ./ssl:/etc/nginx/ssl:ro
      - ./proxy.conf:/etc/nginx/nginx.conf:ro
    depends_on:
      - mynet-quasar
    restart: unless-stopped
    networks:
      - mynet-network

networks:
  mynet-network:
    driver: bridge
```

## ☁️ 云平台部署

### AWS部署

#### S3 + CloudFront 部署

```bash
# 1. 创建S3存储桶
aws s3 mb s3://mynet-quasar-app

# 2. 配置存储桶策略
aws s3api put-bucket-policy --bucket mynet-quasar-app --policy file://s3-policy.json

# 3. 启用静态网站托管
aws s3 website s3://mynet-quasar-app --index-document index.html --error-document index.html

# 4. 上传构建文件
aws s3 sync dist/spa/ s3://mynet-quasar-app/ --delete

# 5. 创建CloudFront分发
aws cloudfront create-distribution --distribution-config file://cloudfront-config.json
```

#### s3-policy.json

```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "PublicReadGetObject",
            "Effect": "Allow",
            "Principal": "*",
            "Action": "s3:GetObject",
            "Resource": "arn:aws:s3:::mynet-quasar-app/*"
        }
    ]
}
```

### Netlify 部署

  command = "npm run build"

  VITE_WS_URL = "wss://api.yourdomain.com/ws"

  from = "/*"
  to = "/index.html"
  status = 200

[[headers]]

  [headers.values]
    X-Frame-Options = "SAMEORIGIN"
    X-XSS-Protection = "1; mode=block"
    X-Content-Type-Options = "nosniff"

[[headers]]
  for = "/*.js"
  [headers.values]
    Cache-Control = "public, max-age=31536000"

[[headers]]
  for = "/*.css"
  [headers.values]
    Cache-Control = "public, max-age=31536000"

## 🚀 CI/CD 部署

### GitHub Actions

```yaml
# .github/workflows/deploy.yml
name: Deploy to Production

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v3
    
    - name: Setup Node.js
      uses: actions/setup-node@v3
      with:
        node-version: '18'
        cache: 'npm'
    
    - name: Install dependencies
      run: npm ci
    
    - name: Run tests
      run: npm run test
    
    - name: Run linting
      run: npm run lint
    
    - name: Type check
      run: npm run type-check

  build:
    needs: test
    runs-on: ubuntu-latest
    if: github.ref == 'refs/heads/main'
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Setup Node.js
      uses: actions/setup-node@v3
      with:
        node-version: '18'
        cache: 'npm'
    
    - name: Install dependencies
      run: npm ci
    
    - name: Build application
      run: npm run build
      env:
        VITE_API_URL: ${{ secrets.VITE_API_URL }}
        VITE_WS_URL: ${{ secrets.VITE_WS_URL }}
    
    - name: Upload build artifacts
      uses: actions/upload-artifact@v3
      with:
        name: dist
        path: dist/spa

  deploy:
    needs: build
    runs-on: ubuntu-latest
    if: github.ref == 'refs/heads/main'
    
    steps:
    - name: Download build artifacts
      uses: actions/download-artifact@v3
      with:
        name: dist
        path: dist
    
    - name: Deploy to S3
      uses: aws-actions/configure-aws-credentials@v2
      with:
        aws-access-key-id: ${{ secrets.AWS_ACCESS_KEY_ID }}
        aws-secret-access-key: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
        aws-region: us-east-1
    
    - name: Sync files to S3
      run: |
        aws s3 sync dist/ s3://${{ secrets.S3_BUCKET }}/ --delete
    
    - name: Invalidate CloudFront
      run: |
        aws cloudfront create-invalidation --distribution-id ${{ secrets.CLOUDFRONT_DISTRIBUTION_ID }} --paths "/*"
```

### GitLab CI/CD

```yaml
# .gitlab-ci.yml
stages:
  - test
  - build
  - deploy

variables:
  NODE_VERSION: "18"

cache:
  paths:
    - node_modules/

test:
  stage: test
  image: node:$NODE_VERSION-alpine
  script:
    - npm ci
    - npm run test
    - npm run lint
    - npm run type-check
  only:
    - merge_requests
    - main

build:
  stage: build
  image: node:$NODE_VERSION-alpine
  script:
    - npm ci
    - npm run build
  artifacts:
    paths:
      - dist/spa
    expire_in: 1 hour
  only:
    - main

deploy_production:
  stage: deploy
  image: alpine:latest
  before_script:
    - apk add --no-cache aws-cli
  script:
    - aws s3 sync dist/spa/ s3://$S3_BUCKET/ --delete
    - aws cloudfront create-invalidation --distribution-id $CLOUDFRONT_DISTRIBUTION_ID --paths "/*"
  only:
    - main
  environment:
    name: production
    url: https://yourdomain.com
```
