# 密钥管理功能升级

## 升级内容

### 1. 动态按钮文本
- **添加密钥模式**：当没有密钥时，显示"添加密钥"按钮
- **更新密钥模式**：当已有密钥时，显示"更新密钥"按钮
- 按钮图标也会相应变化（add/update）

### 2. 风险提示对话框
当用户选择更新密钥时，会弹出明确的风险警告对话框，包含：

#### 风险提醒
- 现有的所有SSH连接将会断开
- 之前配置的公钥访问将失效  
- 需要重新配置所有依赖此密钥的服务
- 如果没有备用访问方式，可能导致节点无法访问

#### 确认要求
- 您有其他方式访问此节点（如控制台访问）
- 已备份重要数据
- 了解如何重新配置相关服务

用户必须确认"我了解风险，继续更新"才能继续操作。

### 3. Force Regenerate 参数
在更新密钥时，API调用会包含 `force_regenerate: true` 参数：

```typescript
// 更新模式下的API调用
const params: any = {}
if (isUpdateMode.value) {
  params.force_regenerate = true
}
const result = await generateKeyPair(params)
```

### 4. 用户体验优化
- **对话框标题**：根据模式显示"生成密钥"或"更新密钥"
- **成功提示**：根据模式显示"密钥生成成功"或"密钥更新成功"
- **私钥保存提醒**：更新时也会正确显示"密钥更新成功！私钥仅显示一次..."

## 使用流程

### 添加密钥（首次）
1. 点击"添加密钥"按钮
2. 选择生成方式（服务端生成/上传公钥）
3. 确认创建
4. 保存私钥

### 更新密钥（已有密钥）
1. 点击"更新密钥"按钮
2. 查看风险警告对话框
3. 确认"我了解风险，继续更新"
4. 选择生成方式（服务端生成/上传公钥）
5. 确认更新（会传递 force_regenerate=true）
6. 保存新的私钥

## 技术实现

### 新增状态变量
```typescript
const showRiskWarningDialog = ref(false)  // 风险警告对话框
const isUpdateMode = ref(false)           // 是否为更新模式
```

### 计算属性
```typescript
const hasKeys = computed(() => keys.value && keys.value.length > 0)
```

### 核心方法
- `handleAddOrUpdateKey()`: 处理添加/更新按钮点击
- `proceedWithKeyUpdate()`: 确认风险后继续更新
- `getCreateButtonText()`: 获取创建按钮文本

## 安全考虑

1. **明确风险提示**：用户必须明确了解更新密钥的风险
2. **强制确认**：不能跳过风险确认步骤
3. **参数传递**：后端通过 force_regenerate 参数识别强制更新操作
4. **私钥保护**：私钥仍然只显示一次，必须立即保存
