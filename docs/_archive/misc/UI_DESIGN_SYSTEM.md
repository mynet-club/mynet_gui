# MyNet UI 设计系统规范

## 一、设计定位（Design Positioning）

### 产品类型
专业级网络/基础设施管理控制台

### UI 气质
- **克制**：只展示必要信息，不过度装饰
- **理性**：数据驱动，状态优先
- **低噪音**：灰阶为主，减少视觉干扰
- **长期耐看**：经典设计，避免流行元素

### 禁止方向
- ❌ 营销化文案（欢迎语、鼓励语）
- ❌ 情绪化设计（渐变背景、emoji）
- ❌ 教程主导（引导卡片、操作提示）
- ❌ 装饰性图标

### UI 目标
**状态一眼可读**，而非"看起来热闹"

---

## 二、设计基准与约束

### UI 母版页面
**设备列表卡片页** (`NodeListPage.vue` + `NodeCardContent.vue`)

所有页面样式必须向设备卡片页对齐，Dashboard 不得拥有独立视觉体系。

### 审美校准参考
**Cloudflare Dashboard**（登录后界面）
- 克制的配色
- 清晰的信息层级
- 专业的数据展示

---

## 三、页面类型强制分级

全站页面**只允许**以下 4 类：

### 1. 实体列表页 (Entity List Page)
- **设备列表** / **路由列表** / **服务列表**
- 使用统一卡片结构
- 示例：`NodeListPage.vue`, `ServiceListPage.vue`

### 2. 实体详情页 (Entity Detail Page)
- **单设备** / **单连接** / **单服务**
- 承载细节信息
- 示例：`NodeDetailPage.vue`

### 3. Dashboard（系统概览页）
- **只显示系统摘要**
- 禁止承载完整信息与教程
- 示例：`DashboardPage.vue`

### 4. 工具/开发页 (Tool/Dev Page)
- API 测试 / Debug / Token 工具
- 示例：`ApiTestPage.vue`, `TokenDebugPage.vue`

---

## 四、卡片系统（核心约束）

### 卡片定义
卡片 = **单一实体的状态聚合单元**，非装饰容器，非教学模块

### 卡片结构（强制统一顺序）

```
┌────────────────────────────────┐
│ 1. Header                      │ ← 实体名称 + 类型图标
│    [Icon] 设备名称        [●]  │
├────────────────────────────────┤
│ 2. Core Status                 │ ← 在线状态 / 延迟 / 连接类型
│    ⚡ 10.182.236.182           │
│    🌐 221.216.141.248 openwrt  │
│    💜 7.7 ms           amd64   │
├────────────────────────────────┤
│ 3. Meta Info                   │ ← IP / 系统 / 架构
│    📍 直连 IPv4                │
├────────────────────────────────┤
│ 4. Footer                      │ ← 归属用户 + 状态 Badge
│    arthur              [在线]  │
└────────────────────────────────┘
```

### 卡片规则
1. **禁止在卡片中出现教程性文案**
2. **禁止在卡片中承载流程引导**
3. **状态优先于说明文字**
4. **技术信息完整展示**，不折叠

## 五、颜色系统（Design Token）

### 基础规则
- 页面灰阶占比 **≥ 70%**
- 主色只用于选中态 / 当前聚焦
- **禁止大面积品牌色背景**

### 状态色（仅语义）

| 状态 | 颜色 | Hex | 使用场景 |
|------|------|-----|----------|
| 正常 | 绿色 | `#10b981` | 在线、已启用、成功 |
| 警告 | 橙色 | `#f59e0b` | 待处理、需注意 |
| 异常 | 红色 | `#ef4444` | 离线、错误、禁用 |
| 不可用 | 灰色 | `#6b7280` | N/A、未配置 |

### 使用约束
- 状态色只用于：**图标** / **Badge** / **数值**
- **禁止状态色背景块**
- 同一视图高饱和色 **≤ 3 种**

### 灰阶系统

```scss
// Light Mode
--gray-50: #f9fafb;   // 背景 - 浅
--gray-100: #f3f4f6;  // 背景 - Header/Footer
--gray-200: #e5e7eb;  // 边框
--gray-300: #d1d5db;  // 分割线
--gray-600: #4b5563;  // 次要文字
--gray-900: #111827;  // 主要文字

// Dark Mode
--gray-800: #1f2937;  // 背景
--gray-700: #374151;  // Header/Footer
--gray-600: #4b5563;  // 边框
--gray-400: #9ca3af;  // 次要文字
--gray-100: #f3f4f6;  // 主要文字
```

## 六、字体与层级规则

### 字体层级

| 用途 | 大小 | 字重 | 颜色 |
|------|------|------|------|
| 页面标题 | 20-22px | 600 | gray-900 |
| 卡片标题 | 16px | 600 | gray-900 |
| 主要数值 | 14-15px | 500 | gray-900 |
| 辅助信息 | 12-13px | 400 | gray-600 |

### 规则
1. **禁止 Bold 滥用**
2. 强调优先使用**颜色与位置**，而非加粗
3. 技术 UI 使用：**短词 + 数值 + 图标**

---

## 七、间距与布局规则

### 间距基础单位
`8px` 为基础单位

### 标准间距

| 用途 | 间距 |
|------|------|
| 卡片内边距 | 16-20px |
| 卡片间距 | 20-24px |
| 模块区块间距 | ≥ 32px |

### 强制规则
1. **卡片之间的间距 > 卡片内部间距**
2. **模块之间必须形成明确"断层"**

---

## 八、Dashboard 去噪与收敛规则（重点）

### Dashboard 的唯一问题
**"系统现在是否正常？"**

### Dashboard 只允许包含

✅ 系统状态概览
- 在线设备数 / 总设备数
- 活跃路由数 / 总路由数
- 服务状态摘要

✅ 问题数量摘要
- 离线设备：X 台
- 待处理连接：X 个
- 未配置设备：X 台

✅ 最近变化（有限条数）
- 最近 5 条状态变化
- 时间戳 + 简短描述

### 必须移出主视觉区的内容

❌ 欢迎语 / 情绪化文案
❌ 教程式引导
❌ 智能推荐卡片（RecommendationsCard）
❌ 强视觉按钮（渐变、大面积色块）

### Dashboard 调整规则

1. **推荐 / 教程** → 次级列表或折叠区域
2. **问题模块** → 合并，只显示数量和跳转链接
3. **快速操作** → 使用次级按钮样式（flat, outlined）
4. **所有卡片样式向设备卡片页对齐**

---

## 九、Dark / Light 模式规则

### 非简单反色
不是简单的黑白翻转

### Light 模式
- 依靠**灰阶区分层级**
- 背景：#ffffff
- 区块背景：#f9fafb, #f3f4f6

### Dark 模式
- 依靠**亮度差区分层级**
- 背景：#111827
- 区块背景：#1f2937, #374151

### Dark 模式状态色
**必须降饱和**，避免刺眼

```scss
// Light Mode
--color-success: #10b981;
--color-warning: #f59e0b;
--color-error: #ef4444;

// Dark Mode
--color-success: #059669;  // 降低饱和度
--color-warning: #d97706;
--color-error: #dc2626;
```

## 十、全站执行硬约束（必须遵守）

### 设计流程约束

1. **新页面必须先判断页面类型**
   - 列表页？详情页？Dashboard？工具页？
   
2. **所有卡片必须复用统一结构**
   - Header → Core Status → Meta Info → Footer

3. **禁止新增"独立设计风格模块"**
   - 必须映射到现有 Design Token

4. **新样式必须能映射到现有 Design Token**
   - 颜色：从灰阶或状态色中选择
   - 间距：8px 倍数

5. **Dashboard 不得拥有视觉特权**
   - 不允许独特背景、字体、间距

## 十一、组件分类与使用规范

### 卡片组件

| 组件 | 用途 | 约束 |
|------|------|------|
| `NodeCardContent` | 设备卡片 | UI 母版，所有卡片向其对齐 |
| `ServiceCardContent` | 服务卡片 | 必须遵循同样结构 |
| `RouteCardContent` | 路由卡片 | 必须遵循同样结构 |

### 禁用组件

| 组件 | 原因 | 替代方案 |
|------|------|----------|
| `RecommendationsCard` | 违反克制原则，包含欢迎语、渐变背景 | 移除或改为次级列表 |
| `WelcomeCard` | 情绪化文案 | 移除 |
| `TutorialCard` | 教程主导 | 移至帮助页面 |

## 十二、代码实施检查清单

### 新建页面检查清单

- [ ] 确定页面类型（列表/详情/Dashboard/工具）
- [ ] 选择正确的卡片组件
- [ ] 颜色只使用 Design Token
- [ ] 间距符合 8px 倍数
- [ ] 无情绪化文案
- [ ] 无教程性内容

### Dashboard 检查清单

- [ ] 无欢迎语
- [ ] 无智能推荐卡片
- [ ] 无渐变背景
- [ ] 无强视觉按钮
- [ ] 只显示状态摘要
- [ ] 问题数量 < 5 项

### 卡片检查清单

- [ ] Header：实体名称 + 图标
- [ ] Core Status：状态信息清晰
- [ ] Meta Info：技术信息完整
- [ ] Footer：归属 + Badge
- [ ] 无教程文案
- [ ] 状态色仅用于图标/Badge
