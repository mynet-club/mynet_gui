# MyNet 用户操作流程

## 默认创建设备

注册并完成既有账号验证 → 首次登录进入创建设备 → 填写名称、选择 GNB / WireGuard → 创建设备 → 查看设备或继续添加。

默认创建只要求两个字段。当前用户在当前网络区没有已分配池时，服务端分配第一组 IP；后续复用用户已有池并取未占用地址。GNB 沿用 9016 / MTU 1450，WireGuard 使用 51820 / MTU 1420；接口名沿用已有权威默认值。首次建池、节点、地址、配置一起提交或回滚。用户行锁串行化默认创建的地址选择。

现有池全部用尽或已禁用时返回明确错误，不静默扩容。表单保留输入，可重试；同一表单提交期间锁定输入和离开操作，阻止重复提交。

成功页持续显示名称、类型和 IP，并说明实际设备接入和密钥配置仍是上线条件。创建设备不会伪装成设备已经在线，也不会自动启用未完成密钥配置的节点。

## 专家入口

默认表单的专家区域提供备注、IP 池管理和旧 OpenVPN 创建入口。端口、接口、MTU 等已有高级表单可从成功页进入专家配置。显式携带 IP 池参数的入口继续使用原创建接口；普通 GNB / WireGuard 默认创建使用扩展后的 quick-create 接口。

设备列表合并原“创建 / 快速创建”为同一个入口；无设备的仪表板提供直接创建按钮。新手引导不再将手工建池作为前置阶段，欢迎提示改为非阻断横幅。

## 连接申请

四步显示当前进度，已完成步骤可返回修改。选项即时存入当前浏览器会话；切换好友会清除后续节点和说明，切换目标会清除来源节点和说明。恢复页面时按最新列表重新验证节点，避免直接沿用已失效选项。

筛选下拉框采用值映射；无匹配结果可清除筛选，加载失败可重试。最终说明随返回操作保留，提交前校验 10–500 字符；提交成功清除草稿，提供待处理请求入口。

## 本机接入与 Tips（2026-10-08）

本地面板登录后可选择已有设备；空列表提供创建设备入口，打开嵌入 GUI 的创建页。选择设备时传递真实 VPN 类型，无法识别时不默认降级为 GNB。

普通接入只需点击“接入本机”：执行器保留并校验已有密钥，缺少密钥时在本机生成，再同步公钥、请求启用设备、发布并下载配置，最后应用配置并启动。失败停在当前步骤，可保留身份直接重试。在线结果以实际状态为准，退化状态不会显示接入完成。手动密钥导入与更换保留在“专家设置”。

欢迎提示和资源池管理不再是创建或完成引导的前置条件。自动提示对已完成阶段不重复展示，延迟弹出的提示会重新检查路由和条件。IP 池帮助与自动分配流程一致，取消自定义私有网段的错误建议。

内嵌 GUI 的创建成功页新增“接入本机”：只向同源父面板发送设备 ID，父面板校验消息来源与云端设备清单后进行接入。平台网页版继续提供设备详情入口，不显示本机操作按钮。已有设备的账号加载引导时根据清单恢复首台/第二台设备里程碑，保留原有提示偏好和关闭记录。
