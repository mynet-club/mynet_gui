# MyNet 统一界面基调

基调：克制、清晰、可信赖。适用于 GUI、桌面面板、后台与 OpenWrt；本次实现范围为 mynet_gui 的共享页面框架与控件。

## 视觉规则

- 品牌蓝 #2563EB：主操作、链接、当前导航。主按钮使用实色，避免青蓝渐变降低白色文字对比度。
- 浅色：冷灰页面、白色表面、深蓝灰正文；深色：分层蓝灰表面、浅色正文。辅助文字浅色 #64748B、深色 #94A3B8。
- 状态色仅承担语义：绿为成功、红为异常、黄为待处理；状态同时提供文字或图标，不仅靠颜色。
- 间距以 8px 为基础；桌面页面边距 32px，小屏 16px。控件圆角 8px，卡片沿用 14px，阴影轻量。
- 静态卡片保持稳定，不因悬停上浮；交互元素提供焦点、悬停和选中反馈。

## 交互规则

- 页面标题、说明、操作区、内容依次排列。操作区可换行，小屏保留按钮文案。
- 导航分组随当前路径展开，也允许手动收起。图标按钮提供可读名称。
- 对话框宽度受视口限制；键盘焦点可见；尊重系统减少动态效果设置。
- 保留鉴权与危险操作确认。普通用户默认采用简化创建流程，详见 USER_FLOWS.md。

## 实现与验证

共享入口为 src/styles/experience.scss；兼容现有主题变量，在旧样式之后加载。页面骨架为 PageLayout.vue；导航和工具栏为 MainLayout.vue。

验收：make check（安全检查、ESLint、i18n、类型棘轮、单元测试）、npm run build；浏览器使用无登录的临时预览挂载实际共享组件，验证桌面与 390px 小屏布局、主题菜单与文案。临时预览不入库。已登录真实业务页面的完整回归需有效测试会话。

2026-10-08 本地结果：make check 通过，35 项单元测试通过；类型棘轮未升（194 条存量错误 / 38 文件）；生产构建成功。共享组件桌面与 390px 小屏均无横向溢出，深色卡片与标题色层级验证通过。浏览器截图接口超时，未完成截图视觉验收；以上为 DOM、交互与计算样式验证。操作流程与后端验收见 [USER_FLOWS.md](USER_FLOWS.md)。
