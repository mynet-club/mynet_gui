# 基本概念

在开始使用 MyNet 之前，了解以下基本概念将有助于您更好地理解和使用系统。

## 🏗️ 核心概念

### 域 (Zone)
**域** 是 MyNet 中最重要的概念之一，它代表一个完全独立的网络环境。

- **定义**: 域是一个逻辑上隔离的网络空间，类似于传统网络中的 VLAN
- **隔离性**: 不同域之间完全隔离，无法直接通信
- **独立管理**: 每个域有独立的用户、节点、路由和服务
- **邀请机制**: 用户只能通过邀请加入特定的域

**示例场景**:
- 公司域：用于企业内部网络
- 家庭域：用于家庭网络管理
- 项目域：用于特定项目的协作

### 节点 (Node)
**节点** 是网络中的基本连接单元，代表一个可以参与网络通信的设备或服务器。

- **定义**: 节点是安装了 MyNet 客户端软件的设备
- **类型**: 可以是服务器、个人电脑、路由器等
- **标识**: 每个节点有唯一的标识符和密钥对
- **功能**: 负责数据转发、服务托管、网络连接等

**节点状态**:
- 🟢 **在线**: 节点正常运行并可访问
- 🟡 **离线**: 节点暂时不可访问
- 🔴 **错误**: 节点配置有问题或故障
- ⚪ **未知**: 节点状态无法确定

### IP 池 (IP Pool)
**IP 池** 是为节点分配 IP 地址的地址资源池。

- **定义**: 一个预定义的 IP 地址范围
- **用途**: 为节点自动分配内网 IP 地址
- **格式**: 支持 CIDR 格式（如 10.0.0.0/24）
- **管理**: 自动分配和回收 IP 地址

**IP 池类型**:
- **私有池**: 仅限域内使用
- **共享池**: 可在多个域间共享
- **静态池**: 手动分配 IP 地址
- **动态池**: 自动分配 IP 地址

### 路由 (Route)
**路由** 定义了节点之间的网络连接和通信路径。

- **定义**: 两个或多个节点之间的网络连接
- **类型**: 点对点连接、网关连接、中继连接
- **协议**: 支持 WireGuard、OpenVPN 等 VPN 协议
- **加密**: 端到端加密通信

**路由状态**:
- 🟢 **活跃**: 路由正常工作
- 🟡 **连接中**: 正在建立连接
- 🔴 **断开**: 连接已断开
- 🔄 **重连中**: 正在尝试重新连接

## 🔐 安全概念

### 密钥管理
MyNet 使用先进的密钥管理系统确保网络安全。

#### 密钥类型
- **公钥**: 用于身份验证和加密通信
- **私钥**: 用户私有，绝不能泄露
- **预共享密钥**: 用于额外的安全层

#### 密钥生成方式
1. **服务器生成**: 系统自动生成密钥对
2. **本地生成**: 用户本地生成并上传公钥
3. **导入现有**: 导入已有的密钥

### 身份认证
- **邀请制**: 新用户必须通过邀请码注册
- **多因素认证**: 支持邮箱验证、短信验证等
- **权限控制**: 基于角色的访问控制（RBAC）

## 🌐 网络概念

### 连接类型

#### 直连
两个节点直接建立连接，无需中间节点转发。

**优点**:
- 延迟最低
- 带宽最大
- 安全性最高

**要求**:
- 两个节点都有公网 IP
- 或者能够 NAT 穿透

#### 中继连接
通过中间节点转发数据的连接方式。

**优点**:
- 可以连接内网节点
- 解决 NAT 穿透问题
- 提高连接成功率

**缺点**:
- 增加延迟
- 占用中继节点带宽

### NAT 穿透
自动处理网络地址转换（NAT）的技术。

- **STUN**: 用于发现公网 IP 和端口
- **TURN**: 当直连失败时提供中继服务
- **ICE**: 综合连接建立协议

## 🔧 服务概念

### 服务类型

#### 私有服务
仅在域内可见和访问的服务。

**特点**:
- 域内隔离
- 访问控制
- 安全性高

#### 公共服务
可以跨域访问的公开服务。

**特点**:
- 需要审批
- 公开可见
- 使用监控

### 服务发现
自动发现和注册网络服务的机制。

- **服务注册**: 节点注册提供的服务
- **服务发现**: 自动发现可用服务
- **健康检查**: 监控服务状态
- **负载均衡**: 自动分配服务请求

## 📊 监控概念

### 连接监控
- **延迟监控**: 实时监控连接延迟
- **带宽监控**: 监控上传/下载速度
- **丢包监控**: 检测网络丢包情况
- **连接质量**: 综合评估连接质量

### 节点监控
- **在线状态**: 节点是否在线
- **资源使用**: CPU、内存、存储使用情况
- **服务状态**: 节点提供的服务状态
- **安全状态**: 安全威胁和漏洞监控

## 🚀 操作概念

### 工作流程
MyNet 的典型使用流程：

1. **注册加入** → 通过邀请码注册并加入域
2. **创建资源** → 创建 IP 池和节点
3. **建立连接** → 与其他节点建立路由
4. **发布服务** → 发布和使用网络服务
5. **监控维护** → 监控网络状态和性能

### 最佳实践
- **规划先行**: 提前规划网络拓扑和 IP 地址分配
- **安全第一**: 定期更新密钥和检查安全配置
- **监控为本**: 持续监控网络状态和性能
- **文档记录**: 记录重要的配置和变更
