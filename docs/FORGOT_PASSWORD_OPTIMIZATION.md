# 忘记密码流程优化文档

## 修改概述

基于用户反馈，对忘记密码的交互流程进行了重大优化，解决了重复输入邮箱的问题，改为更流畅的页面跳转流程。

## 🔄 流程变更

### 修改前的流程
1. 用户输入邮箱 → 点击发送
2. **弹出对话框** → 再次输入邮箱 (重复操作)
3. 选择重置方式 → 输入验证码/点击邮件链接
4. 设置新密码

### 修改后的流程
1. 用户输入邮箱 → 点击发送 → **直接跳转到验证码页面**
2. 输入验证码验证 → **跳转到密码重置页面**  
3. 设置新密码 → **显示成功提示**

## ✨ 核心改进

### 1. 去除弹窗交互
- **移除** `PasswordResetDialog` 弹窗组件的使用
- **改为** 页面跳转，提供更好的用户体验
- 避免了二次确认邮箱的困扰

### 2. 优化页面流程
- **忘记密码页面** (`/auth/forgot-password`) → 直接调用API发送验证码
- **验证码页面** (`/auth/reset-verification`) → 输入6位验证码
- **密码重置页面** (`/auth/reset-password`) → 设置新密码

### 3. 邮件链接作为备用方案
- 主要流程走验证码模式，适合所有客户端
- 邮件链接仍然可用，但作为"暗线"备用方案
- 在web环境下，用户仍可点击邮件链接直接重置

## 🛠️ 技术实现

### 修改的文件

#### 1. ForgotPasswordForm.vue
```typescript
// 修改前：显示弹窗
showResetDialog.value = true

// 修改后：直接跳转页面
await router.push({
  path: '/auth/reset-verification',
  query: { email: forgotPasswordForm.email }
})
```

#### 2. 新增 ResetVerificationPage.vue
- 专门的验证码输入页面
- 自动读取URL中的邮箱参数
- 60秒倒计时重发功能
- 验证成功后跳转到密码重置页面

#### 3. 新增 NewResetPasswordPage.vue
- 简化的密码重置页面（移除步骤器）
- 密码强度实时检测
- 重置成功后自动跳转登录页

#### 4. useAuth.ts 增强
```typescript
// 支持传参的 forgotPassword 方法
const forgotPassword = async (data?: { email: string; redirect_url?: string })
```

### 路由配置更新
```typescript
{ path: 'reset-verification', component: () => import('../pages/auth/ResetVerificationPage.vue') },
{ path: 'reset-password', component: () => import('../pages/auth/NewResetPasswordPage.vue') },
```

### 国际化支持

- `didntReceiveCode`: "没有收到验证码？"
- `resendCodeCountdown`: "重新发送 ({seconds}s)"
