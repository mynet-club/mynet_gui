# 活跃路由页面 - 星图视图（网络拓扑图）

## 功能概述

为活跃路由页面新增了**星图模式**（网络拓扑视图），以可视化的方式展示当前节点与其他节点的连接关系。采用星形网络拓扑布局，中心节点为当前选择的节点，周围以圆形分布展示所有对端节点。

## 视图模式

活跃路由页面现在支持**三种视图模式**：

| 模式 | 图标 | 路由 | 说明 |
|-----|------|------|------|
| 卡片 | grid_view | `/app/routes/active/:nodeId` | 网格卡片布局，按用户分组 |
| 列表 | list | `/app/routes/active/:nodeId/list` | 表格列表布局，支持搜索和排序 |
| 星图 | hub | `/app/routes/active/:nodeId/topology` | 网络拓扑图，直观展示连接关系 |

## 星图视图特性

### 1. 可视化元素

#### 中心节点（当前节点）
- **大小**: 半径 40px，比对端节点更大
- **颜色**: 蓝色 (#1976d2)
- **图标**: 🖥️ 电脑图标
- **标签**: 显示节点名称和"当前节点"标识
- **位置**: 固定在画布中心

#### 对端节点
- **大小**: 半径 30px
- **颜色**: 根据节点状态动态显示
  - 🟢 绿色 - 在线 (node_status = 2)
  - 🟠 橙色 - 启用但离线 (node_status = 1)
  - ⚪ 灰色 - 已禁用 (node_status = 0)
  - 🟡 黄色 - 未完成配置 (node_status = -1)
- **图标**: 💻 电脑图标
- **标签**: 节点名称（超过12字符自动截断）
- **状态**: 显示节点状态文本
- **延迟**: 在线节点显示延迟时间（ms）
- **布局**: 以圆形均匀分布在中心节点周围

#### 连接线
- **颜色**:
  - 🟢 绿色 - 直连 (direct_ipv4/direct_ipv6)
  - 🔵 蓝色 - 中继连接 (relay/derp)
  - ⚪ 灰色 - 无连接 (none)
- **样式**:
  - 实线 - 在线连接
  - 虚线 - 离线连接
- **宽度**: 根据延迟动态调整
  - 4px - 延迟 < 50ms（优秀）
  - 3px - 延迟 50-100ms（良好）
  - 2px - 延迟 > 100ms（一般）
- **交互**: 鼠标悬停时加粗显示

### 2. 交互功能

#### 缩放控制
- **放大按钮** (zoom_in): 放大视图（最大3倍）
- **缩小按钮** (zoom_out): 缩小视图（最小0.3倍）
- **重置按钮** (center_focus_strong): 恢复默认视图
- **鼠标滚轮**: 滚动缩放（向上放大，向下缩小）

#### 节点交互
- **点击对端节点**: 打开节点详情弹窗
- **点击中心节点**: 可扩展为显示当前节点详情
- **鼠标悬停**: 连接线加粗，节点高亮

#### 详情弹窗
显示选中节点的完整信息：
- 节点状态（带颜色标签）
- 连接状态（在线/离线）
- 连接类型（直连/中继）
- 延迟时间
- 所属用户
- IP地址列表
- 流量统计（上传/下载）
- **操作按钮**: "查看详情"跳转到连接详情页

### 3. 图例说明

视图底部显示图例，帮助理解各种视觉元素的含义：

**节点状态：**
- 🟢 在线
- 🟠 启用但离线
- ⚪ 已禁用
- 🟡 未完成配置

**连接类型：**
- ━━━ 实线：直连
- ━━━ 实线：中继
- ┄┄┄ 虚线：无连接

## 技术实现

### 组件结构

```
NodeTopologyView.vue (新组件)
├── SVG 拓扑图
│   ├── 连接线组 (connections-group)
│   ├── 对端节点组 (peer-nodes-group)
│   └── 中心节点 (center-node)
├── 工具栏 (放大/缩小/重置)
├── 图例 (topology-legend)
└── 节点详情弹窗 (q-dialog)
```

### 布局算法

**圆形分布算法：**
```typescript
// 计算每个节点的位置
const radius = Math.min(svgWidth, svgHeight) * 0.35
const count = connections.length
const angle = (2 * Math.PI * index) / count - Math.PI / 2

const x = centerX + radius * Math.cos(angle)
const y = centerY + radius * Math.sin(angle)
```

- 半径为画布较小边的 35%
- 节点均匀分布在圆周上
- 起始角度为 -90°（12点钟方向）

### 响应式设计

- **容器**: 自适应父容器宽度，最小高度 600px
- **SVG**: 动态调整尺寸，监听窗口 resize 事件
- **节点数量变化**: 自动重新计算布局
- **视图重置**: 连接数量变化时自动重置缩放

### 性能优化

- 使用原生 SVG，无需额外库
- 计算属性缓存节点位置
- 事件委托处理节点交互
- 仅在需要时更新 DOM

## 使用场景

### 1. 快速了解网络拓扑
- 一目了然地查看当前节点与多少其他节点建立了连接
- 快速识别在线/离线节点
- 发现连接类型分布（直连vs中继）

### 2. 网络质量监控
- 通过连接线颜色和宽度判断连接质量
- 延迟数值直观显示在节点上方
- 快速发现高延迟或不稳定的连接

### 3. 故障排查
- 离线节点以虚线和灰色标识，易于定位
- 节点状态标签清晰显示配置问题
- 点击节点查看详细信息，深入分析

### 4. 用户演示
- 可视化展示比列表更直观
- 适合向非技术用户解释网络结构
- 缩放功能便于关注特定节点


## 数据流

```
ActiveRoutesPage
  ↓ (获取数据)
API: /monitor/history/connections?node_id=xxx&last=1
  ↓ (返回)
{
  connections: [...],      // 连接状态
  nodes_metadata: {...}    // 节点信息
}
  ↓ (处理合并)
processedConnections
  ↓ (传递给组件)
NodeTopologyView
  ↓ (计算布局)
visualConnections (圆形分布坐标)
  ↓ (渲染)
SVG 拓扑图
```
