MyNet 网络配置功能测试说明

1. API 端点信息

获取可用IP: GET /api/v1/ippools/available-ips
更新网络配置: PUT /api/v1/nodes/{node_id}/network-config

2. 网络配置字段

网络接口名称 (ifname)
string, required
网络接口名称，如 eth0, wlan0, tun0 等
默认值规则:
  • gnb → gnb_tun
  • wireguard → WG01
  • openvpn → tun0
  • 其他 → tun0
节点虚拟IP (node_ip)
string, required
从IP池中选择的虚拟IP地址
IP组序号 (ip_group_sequence_number)
number, required
选择IP时自动获取的组序号
索引服务器 (index_servers)
array[string], optional
多个索引服务器地址，格式: IP:端口
局域网IP (lan_ips)
array[string], optional
多个局域网IP地址，格式: IP:端口
公网IP (public_ip)
string, optional
公网IP地址，提升连接速度

3. 功能测试清单

  • ✅ 网络接口名称根据VPN类型自动设置默认值
  • ✅ 节点虚拟IP通过对话框选择，支持搜索和分组显示
  • ✅ 选择IP时自动保存IP组序号
  • ✅ 索引服务器支持多个，可添加/删除
  • ✅ 局域网IP支持多个，可添加/删除
  • ✅ 表单验证：网络接口名称、节点虚拟IP必填
  • ✅ 提交时数据格式正确，调用正确的API端点
  • ✅ 错误处理和用户反馈

4. 访问地址

在浏览器中访问: http://localhost:8080/nodes/1/edit/network

注意：需要先启动开发服务器 npm run dev
