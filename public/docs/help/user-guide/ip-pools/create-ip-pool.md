# 创建 IP 池

IP 池是 MyNet 网络管理的基础设施，它为您的节点提供 IP 地址分配。本指南将详细介绍如何创建和配置 IP 池。

## 📋 前提条件

在创建 IP 池之前，请确保：

- ✅ 已完成账号注册和激活
- ✅ 已登录 MyNet 系统
- ✅ 具有创建 IP 池的权限
- ✅ 了解基本的网络概念（IP 地址、子网掩码等）

## 🎯 创建流程

### 第一步：进入 IP 池管理页面

1. 登录 MyNet 系统
2. 在左侧导航菜单中点击 **"IP 池管理"**
3. 进入 IP 池列表页面
4. 点击右上角的 **"创建 IP 池"** 按钮

![IP池管理页面](../../assets/images/ippool-list.png)

### 第二步：填写基本信息

#### 池名称 📝
- **要求**：3-50 个字符
- **格式**：支持中文、英文、数字、连字符
- **建议**：使用描述性名称，如 "办公网络池"、"测试环境池"
- **示例**：`office-network-pool`

#### 池描述 📄
- **长度**：最多 200 个字符
- **用途**：描述 IP 池的用途和适用场景
- **示例**：
  ```
  用于办公室内部网络设备的 IP 地址分配，
  包括员工工作设备和打印机等网络设备。
  ```

### 第三步：配置网络参数

#### IP 地址范围 🌐

**CIDR 格式**
- **定义**：使用 CIDR（无类别域间路由）格式
- **格式**：`网络地址/子网掩码位数`
- **示例**：
  - `10.0.0.0/24` - 可分配 254 个 IP 地址（10.0.0.1 - 10.0.0.254）
  - `192.168.1.0/24` - 可分配 254 个 IP 地址
  - `172.16.0.0/16` - 可分配 65,534 个 IP 地址

**推荐的私有 IP 范围**：
| 类别 | IP 范围 | CIDR 示例 | 适用场景 |
|------|---------|-----------|----------|
| A 类 | 10.0.0.0 - 10.255.255.255 | 10.0.0.0/8 | 大型企业网络 |
| B 类 | 172.16.0.0 - 172.31.255.255 | 172.16.0.0/12 | 中型企业网络 |
| C 类 | 192.168.0.0 - 192.168.255.255 | 192.168.1.0/24 | 小型办公网络 |

#### 网关设置 🚪

**自动网关**（推荐）
- 系统自动分配网关地址
- 通常是网段的第一个可用 IP
- 例如：`10.0.0.0/24` 的网关是 `10.0.0.1`

**自定义网关**
- 手动指定网关 IP 地址
- 必须在指定的网络范围内
- 用于特殊网络拓扑需求

#### DNS 配置 🔍

**系统默认 DNS**
- 使用 MyNet 推荐的 DNS 服务器
- 提供最佳的解析性能
- 包括内网域名解析

**自定义 DNS**
- 指定自己的 DNS 服务器
- 支持多个 DNS 服务器（主/备）
- 常用公共 DNS：
  - Google DNS：`8.8.8.8`, `8.8.4.4`
  - Cloudflare DNS：`1.1.1.1`, `1.0.0.1`
  - 阿里 DNS：`223.5.5.5`, `223.6.6.6`

### 第四步：高级配置

#### IP 分配策略 📊

**动态分配**（推荐）
- 自动为新节点分配 IP 地址
- 支持 IP 地址回收和重用
- 适合大多数使用场景

**静态分配**
- 手动为每个节点指定 IP 地址
- IP 地址固定不变
- 适合服务器和关键设备

**混合模式**
- 部分 IP 地址静态分配
- 剩余地址动态分配
- 兼顾稳定性和灵活性

#### 保留地址 🔒

为特殊用途保留某些 IP 地址：

**系统保留**
- 网络地址（如 10.0.0.0）
- 广播地址（如 10.0.0.255）
- 网关地址（如 10.0.0.1）

**自定义保留**
- 为服务器预留地址
- 为网络设备预留地址
- 为未来扩展预留地址

#### 生命周期管理 ⏰

**IP 租期**
- 设置 IP 地址的有效期
- 过期后自动回收
- 防止 IP 地址浪费

**自动清理**
- 清理长期离线的节点
- 回收未使用的 IP 地址
- 优化地址池利用率

### 第五步：权限设置

#### 访问控制 🔐

**域内共享**
- IP 池在当前域内共享
- 域内所有用户可使用
- 适合团队协作场景

**私有使用**
- 仅创建者可以使用
- 其他用户无法访问
- 适合个人测试环境

**指定用户**
- 选择特定用户分享
- 精确控制访问权限
- 适合项目团队

#### 操作权限 ⚙️

**只读权限**
- 可以查看 IP 池信息
- 无法修改配置
- 适合普通用户

**使用权限**
- 可以从池中获取 IP 地址
- 可以释放已分配的 IP
- 适合节点管理员

**管理权限**
- 可以修改 IP 池配置
- 可以管理所有分配
- 适合网络管理员

## ✅ 创建完成

### 验证 IP 池

创建完成后，系统会自动验证：

1. **网络配置验证** ✔️
   - 检查 CIDR 格式是否正确
   - 验证网关地址是否有效
   - 确认 DNS 服务器可访问

2. **冲突检测** ✔️
   - 检查与现有 IP 池的冲突
   - 验证地址范围不重叠
   - 确保网络拓扑合理

3. **权限检查** ✔️
   - 验证用户权限
   - 检查配额限制
   - 确认操作合规

### 初始化数据

IP 池创建成功后：

- 📊 **统计信息**：显示总地址数、可用地址数
- 🎯 **分配状态**：准备接受节点 IP 分配请求
- 📝 **操作日志**：记录创建操作和配置信息
- 🔔 **通知推送**：向相关用户发送创建成功通知

## 📊 最佳实践

### 网络规划建议

#### 小型网络（< 50 个设备）
```
推荐配置：
- CIDR: 192.168.1.0/24
- 可用 IP: 254 个
- 网关: 192.168.1.1
- DNS: 系统默认
```

#### 中型网络（50-500 个设备）
```
推荐配置：
- CIDR: 172.16.0.0/16
- 可用 IP: 65,534 个
- 网关: 172.16.0.1
- DNS: 自定义（多个）
```

#### 大型网络（> 500 个设备）
```
推荐配置：
- CIDR: 10.0.0.0/8
- 可用 IP: 16,777,214 个
- 多个子网分段管理
- 专业 DNS 配置
```

### 安全考虑

1. **网络隔离** 🔒
   - 不同用途的网络使用不同 IP 池
   - 生产环境与测试环境分离
   - 敏感服务使用独立网段

2. **访问控制** 🛡️
   - 最小权限原则
   - 定期审查用户权限
   - 及时清理无效账号

3. **监控告警** 📊
   - 监控 IP 使用率
   - 设置使用率告警
   - 记录异常分配行为

## 🔧 故障排除

### 常见错误

#### 创建失败
**错误信息**：`IP 池创建失败`

**可能原因**：
- CIDR 格式错误
- IP 范围与现有池冲突
- 权限不足
- 网络配置无效

**解决方案**：
1. 检查 CIDR 格式是否正确
2. 验证 IP 范围是否冲突
3. 确认账号权限
4. 联系管理员检查配置

#### 地址冲突
**错误信息**：`IP 地址范围冲突`

**解决方案**：
1. 查看现有 IP 池列表
2. 选择不冲突的地址范围
3. 使用系统推荐的地址段
4. 考虑使用子网划分

#### 权限错误
**错误信息**：`权限不足`

**解决方案**：
1. 联系域管理员申请权限
2. 检查用户角色配置
3. 确认域成员身份
4. 重新登录刷新权限
