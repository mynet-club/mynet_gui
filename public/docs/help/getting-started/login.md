# 登录系统

完成账号注册和激活后，您可以使用以下方式登录 MyNet 系统。

## 🔐 登录方式

### 标准登录

使用您注册时设置的用户名/邮箱和密码进行登录。

#### 访问登录页面
1. 打开 MyNet 官网
2. 点击右上角 **"登录"** 按钮
3. 进入登录页面

#### 输入登录信息

![登录界面](../assets/images/login-form.png)

**用户标识** 📧
- 可以使用用户名或邮箱地址
- 不区分大小写
- 例如：`john_doe` 或 `john@example.com`

**密码** 🔑
- 输入注册时设置的密码
- 区分大小写
- 建议使用密码管理器

**记住我** ☑️
- 勾选后下次访问自动登录
- 仅在私人设备上使用
- 有效期：30 天

### 快速登录选项

#### 邮箱快速登录
如果忘记了用户名，可以直接使用邮箱登录：
1. 点击 **"使用邮箱登录"**
2. 输入注册邮箱
3. 输入密码

#### 手机验证登录
如果绑定了手机号码：
1. 点击 **"手机验证登录"**
2. 输入手机号码
3. 获取并输入验证码

## 🔄 忘记密码

### 密码重置流程

1. **点击重置链接**
   - 在登录页面点击 **"忘记密码？"**
   
2. **输入邮箱**
   - 输入注册时使用的邮箱地址
   - 点击 **"发送重置邮件"**

3. **检查邮箱**
   - 查收密码重置邮件
   - 邮件通常在 5 分钟内到达

4. **重置密码**
   - 点击邮件中的重置链接
   - 设置新密码
   - 确认新密码

### 重置邮件内容

**邮件主题**：MyNet 密码重置请求

**邮件内容**：
```
您好，

您请求重置 MyNet 账号密码。请点击下面的链接重置密码：

[重置密码] (有效期：24小时)

如果您没有请求重置密码，请忽略此邮件。

MyNet 团队
```

## 🔒 安全验证

### 多因素认证 (MFA)

如果您启用了多因素认证，登录时需要额外验证：

#### 邮箱验证
1. 输入用户名密码后
2. 系统发送验证码到邮箱
3. 输入 6 位验证码
4. 点击 **"验证"**

#### 短信验证
1. 输入用户名密码后
2. 系统发送验证码到手机
3. 输入 6 位验证码
4. 点击 **"验证"**

#### TOTP 验证
如果使用认证器应用：
1. 打开认证器应用（如 Google Authenticator）
2. 查看 MyNet 的 6 位验证码
3. 输入验证码
4. 点击 **"验证"**

### 设备识别

MyNet 会记住您的登录设备：

**信任设备** ✅
- 经常使用的设备会被标记为信任设备
- 信任设备登录时验证流程简化
- 可在设置中管理信任设备

**新设备登录** ⚠️
- 新设备登录时需要额外验证
- 邮箱会收到登录通知
- 可以选择信任新设备

## 🌐 多域登录

### 域切换

如果您属于多个域，登录后可以切换域：

1. **查看当前域**
   - 顶部导航栏显示当前域名
   
2. **切换域**
   - 点击域名下拉菜单
   - 选择要切换的域
   - 确认切换

3. **域权限**
   - 不同域有不同的权限
   - 切换域后界面可能有所不同

### 域邀请

如果有朋友邀请您加入新域：

1. **接收邀请**
   - 邮箱收到域邀请邮件
   - 或通过邀请链接
   
2. **加入域**
   - 登录后点击邀请链接
   - 确认加入新域
   - 新域会出现在域列表中

- ⚡ **快速操作**：常用功能快捷入口

- 🏠 **仪表盘**：系统概览和统计
- 🖥️ **节点管理**：管理网络节点
- 🔗 **路由管理**：配置网络路由

## 🛠️ 登录问题排除

### 无法登录

#### 密码错误
- **症状**：提示密码错误
- **解决**：
  - 检查 Caps Lock 是否开启
  - 确认密码输入正确
  - 使用 [密码重置](#密码重置流程) 功能

#### 账号被锁定
- **症状**：提示账号被锁定
- **原因**：连续输入错误密码 5 次
- **解决**：
  - 等待 30 分钟后重试
  - 或联系技术支持解锁

#### 验证码错误
- **症状**：多因素认证验证码错误
- **解决**：
  - 检查手机/邮箱验证码
  - 确认时间同步（TOTP）
  - 重新获取验证码

### 网络问题

#### 连接超时
- **症状**：页面加载缓慢或超时
- **解决**：
  - 检查网络连接
  - 尝试刷新页面
  - 清除浏览器缓存

#### DNS 解析失败
- **症状**：无法访问网站
- **解决**：
  - 更换 DNS 服务器
  - 使用移动网络测试
  - 联系网络服务商

## 🔒 安全建议

### 密码安全
- 🔐 使用强密码（大小写字母、数字、特殊字符）
- 🔄 定期更换密码（建议 3-6 个月）
- 🚫 不要在多个网站使用相同密码
- 💾 使用密码管理器存储密码

### 登录安全
- 🏠 仅在信任的设备上选择 "记住我"
- 🔒 使用后及时退出登录（公共设备）
- 📱 启用多因素认证增强安全性
- 👀 定期检查登录记录

### 网络安全
- 🔐 避免在公共 WiFi 上登录
- 🛡️ 确保浏览器 HTTPS 连接
- 🔄 保持浏览器版本更新
- 🚫 不点击可疑邮件中的登录链接
